# Probability Statistics
• In the **[Rolling the Dice](./Rolling%20the%20dice/)** folder, we learn the concept of **Expected Value** through a simple dice-rolling example.

• In the **[plotly-pmf](./plotly-pmf/)** folder, A simple Python function for plotting a Probability Mass Function (PMF) of a discrete random variable using Plotly.

• In the **[Estimating Pi using the Monte Carlo](./Estimating%20Pi%20using%20the%20Monte%20Carlo/)** folder, This project demonstrates how the value of π (Pi) can be estimated using the Monte Carlo Method and randomly generated points.
